## 📌 VERSIONING POLICY

AI Vision Hub uses semantic versioning:

`MAJOR.MINOR.PATCH`

- **MAJOR:** Incompatible architecture or API changes.
- **MINOR:** New functionality that remains compatible.
- **PATCH:** Bug fixes and minor improvements.
